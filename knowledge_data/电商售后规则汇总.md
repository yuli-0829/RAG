## 一、售后总则（商家售后服务管理规范）

> 原文链接：https://school.jinritemai.com/doudian/wap/article/104600
> 生效时间：2020年10月25日首次生效，2026年8月26日修订生效

### 第一章 概述

**1.1 目的及依据**

为了规范平台内商家的售后服务，提升消费者服务体验，维护平台经营生态秩序，根据《电子商务法》《消费者权益保护法》及相关法律法规，制定本规范。

**1.2 适用范围**

适用于平台内所有商家（即时零售、全球购商家除外）。

**1.3 效力级别**

本规则是对"平台规则体系"的有效补充。商家应遵守国家法律、行政法规、部门规章、平台规则以及与平台签订的各项协议。

### 第二章 服务要求

**2.1 定义**

商家应根据法律规定、平台规则要求、对消费者的承诺，履行对消费者的服务义务。售后服务包括但不限于：退款、退货退款、换货、补寄、维修、商家承诺的服务、发货后修改地址等。

- 退款：适用于所有商品订单
- 退货退款：适用于非特殊商品订单（虚拟商品等除外）
- 换货/补寄/维修：适用于部分类目商品

**2.2 售后服务原则**

- **售后服务基础要求**：商家应按规定期限提供退货、换货、维修等售后服务，并按三包规定提供三包服务。如商家承诺的售后服务标准高于法律法规或平台规则要求，应按对消费者更有利的承诺执行。
- **售后协商与争议处理**：鼓励双方协商解决；无法协商一致的，平台依据《售后争议处理总则》及相关细则处理。
- **退货地址管理**：商家需预留正确的售后收件地址及联系方式，如因地址异常导致消费者无法寄回商品，平台有权支持消费者退款。
- **售后处理时效要求**：商家收到服务请求/售后申请后，应在平台规定时效内处理。

**2.3 售后服务规范**

#### （一）通用规则

1. **消费者寄回时限**：商家同意退货退款/换货/维修申请后，消费者应在7天内完成原商品寄回。逾期未寄回的，视为未处理，在有效期内仍可重新提交。
2. **撤销与退款说明**：消费者在商家处理前可撤销售后申请；商家同意退款后，系统自动退款至原支付账户。

#### （二）分场景规则

| 售后类型 | 申请处理时效 | 退款/发货处理 | 赔付规则 |
|---|---|---|---|
| **发货前退款** | 商家24小时内处理，超时默认同意 | 不涉及 | 不涉及 |
| **已发货退款** | 商家36小时内处理，超时默认同意 | 不涉及 | 不涉及 |
| **退货退款** | 商家36小时内处理，超时默认同意 | 消费者寄出后7天内完成退款/拒绝；物流签收后：极速退款订单72小时内，其他48小时内 | 不涉及 |
| **换货** | 商家36小时内处理，超时默认同意 | 消费者寄出后7天内完成换货发货并上传单号；签收后48小时内完成 | 换货未履约：按订单实付金额30%赔付（最低6元，最高50元） |
| **补寄** | 商家48小时内处理，超时默认同意 | 同意后24小时内完成发货，消费者发货后7日内收到 | 补寄未履约：支持退款 + 按实付金额30%赔付（最低6元，最高50元） |
| **维修** | 商家48小时内处理，超时默认同意 | 寄出后7天内完成收货确认及检测；签收后48小时内完成。符合维修标准的，签收之日起20日内完成维修并寄回 | 维修未履约：按实付金额30%赔付（最低6元，最高200元）；维修超时：2%×超时天数（上限30%，最低6元，最高200元） |

#### （三）极速退款要求

满足以下条件时，系统自动退款给消费者：
1. 商家未发货，消费者发起退款（平台根据消费者信誉等因素决定）
2. 商家已发货但消费者未签收或已拒签：物流显示丢件/拒签、无有效揽收记录、商家存在发货违规、平台研判商品存在问题等
3. 消费者发起退货退款，上传退货物流单号已有有效轨迹（平台根据消费者信誉等决定）

#### （四）其他要求

1. 商家拒绝售后申请前需与消费者沟通；消费者不认可可在5天内修改再次提交或申请平台介入
2. 商家无故拒绝或超时处理，平台依据《【商家—消极服务】细则》处置
3. 双方达成补偿/退赔协议后，无其他约定的，商家需在24小时内执行
4. 商家不得以运费、服务费等理由造成消费者实际收到的退款少于实际支付金额
5. 商家未履行服务承诺的，平台有权做退货退款/退款处理，并按订单实付金额5%赔付（最低5元，最高30元）
6. 商家承诺评价返现未履行的，按承诺金额或实付金额5%赔付（最低1元，最高5元）

## 二、争议处理（售后争议处理总则）

> 原文链接：https://school.jinritemai.com/doudian/web/article/101832

### 第一章 总则

- **第1条**：本规则适用于本平台交易产生的争议。
- **第2条**：本规则是平台争议处理的基础规则，对平台及所有交易主体均有协议约束力。

### 第二章 争议受理

#### 第一节 受理期限

- **第3条**：消费者应在"商家售后服务有效期"结束前申请平台介入；商品/类目有特殊规定的从其规定。
- **第4条**：以下情形不受受理期限限制：
  - 行政机关认定为假冒或违禁商品的
  - 消费者提供司法机关生效法律文书的
  - 消费者未在期限内发起，但能提供凭证或平台基于数据认定未收到货或存在描述不当、伪劣等导致权益受损的

#### 第二节 受理范围

- **第5条**：以下情形平台可不予受理：
  - 消费者未在受理期限内反馈
  - 交易订单显示与实际约定不一致，导致事实无法查清
  - 不以真实交易为目的的订单
  - 交易做退款处理后，因商家取回商品产生的争议
  - 消费者主张额外损失或法定赔偿，超出平台处理范围的

#### 第三节 介入原则

- **第6条**：平台作为独立第三方，根据争议事实及平台规则作出判断。优先尊重交易主体自行协商结果。
- **第7条**：买卖双方对证据的真实性、关联性、完整性负责；平台以普通人认知判断，除故意或重大过失外免责。
- **第8条**：交易主体应在规定时间内（一般24小时内）提供证据材料，否则承担举证不利后果。
- **第9条**：平台必要时可向第三方核实争议问题。
- **第10条**：平台基于大数据能力，对商家过往行为、违规记录、客诉、评价、质量抽检等综合研判，介入店铺订单或处理争议。常见情形包括：商品描述不符/虚假宣传/假冒/伪劣、商家违规、商品发布不合规、好评率低于70%等。

### 第三章 争议处理

#### 第一节 通用规则

- **第11条**：交易主体有约定的优先从约定；未约定或约定不明的按本规则处理。
- **第12条**：争议过程中按规则举证；规则未规定或账号异常的，平台视情况分配举证责任。
- **第13条**：商家将商品交付承运人后签收完成前，商品风险由卖家承担。
- **第14条**：非消费者原因退货时：
  - 商品因质量问题等致使合同目的不能实现的，消费者交付承运人后，破损/损毁/灭失风险由商家承担，交易支持退款
  - 商家同意退货但无确切证据证明有责的，消费者交付承运人后，破损风险由商家承担，损毁/灭失风险由消费者承担
- **第15条**：消费者合理拒收或非因消费者过错未收到商品的，订单支持退款，在途风险由商家承担。
- **第16条**：商品存在轻微瑕疵或描述问题，消费者主张减少价款的，平台予以支持，退款金额最高不超过订单实付金额的30%。
- **第17条**：商品不适宜退货、退货成本高于商品价值、或因商家原因无法退货的，订单支持退款。
- **第18条**：消费者已退回商品，商家认为不符合退款条件但无法提供有效凭证的，订单支持退款。

#### 第二节 发货规范

- **第19条**：消费者需确保收件信息真实准确，因信息错误导致未收到商品的由消费者承担后果。
- **第20条**：消费者变更收件信息需征得商家同意；商家同意后仍按原地址签收的，支持退款或退货退款。
- **第21条**：商家发货前消费者申请退款的，商家应停止发货；强行发货的，消费者有权拒收。
- **第22条**：运输途中消费者基于合理需求申请退款的，商家应拦截，拦截成功后支持退款。
- **第23条**：商家需按承诺方式发货，否则消费者有权拒收；非包邮订单已签收的，商家应退还已支付运费。
- **第24条**：商家对每个独立订单应单独发货，未经同意不得合并包裹。
- **第25条**：物流流转/派件超时/异常的，商家应积极核实并同步进展。
- **第26条**：商家违反发货规范的，支持消费者拒收、退货退款。

#### 第三节 签收规范

- **第27条**：商家应将商品送达至收货地址并交由收件人本人签收；未经同意放快递柜/站点的，消费者投诉未收到货的，商家需提供签收凭证，否则支持退款。
- **第28条**：收件人委托他人签收或按指示置于指定地点的，视为本人签收。
- **第29条**：消费者主张未收到货或商家主张未收到退货的，由寄件方承担举证责任。
- **第30条**：需到指定地点提取的，应事先征得对方同意，否则收货方有权拒签。

#### 第四节 退货、换货、维修规范

- **第31条**：商家应确保默认退货地址正确；因地址问题导致无法退货的，支持退款，商品由商家负责取回。
- **第32条**：使用到付方式退回商品应事先征得对方同意。
- **第33条**：退货物流到商家当地后应及时签收验货；经提醒仍未签收的，视为无异议，支持退款。
- **第34条**：退货存在特殊要求/门槛的，商家应前置提醒；未提醒的，平台有权支持退款。
- **第35条**：消费者主观原因退换货的，商家提供商品影响二次销售凭证的，支持商家；轻微影响的，可折价退款。
- **第36条**：退货商品不符合退款条件但商家已签收的，应寄回商品，否则仍支持退款。
- **第37条**：不支持7天无理由或性质不适宜拒签的商品，消费者无正当理由拒签的，支持商家，消费者承担物流费用及毁损灭失风险。
- **第38条**：QIC质检发货的珠宝首饰类商品，因消费者原因退货需同时寄回鉴定证书；未寄回或破损的，扣除鉴定费用。
- **第39条**：商家出售临近保质期商品应事先显著明示或征得同意，否则消费者有权拒签或要求退货。
- **第40条**：各规定间存在矛盾的，按最有利于消费者的标准执行。
- **第41条**：以换代修时，换货商品在原三包期内出现质量问题的，换货次数视同一次维修记录。

#### 第五节 运费规范

- **第42条**：平台介入前自行达成协议但未约定运费的，由商家承担；介入后按"谁过错、谁承担"原则处理。
- **第43条**：商家未经同意到付发货的，消费者可拒签或要求商家承担到付费。
- **第44条**：支持7天无理由退货的商品，消费者无理由退换或拒签的：
  - 非包邮商品或部分退货致无法满足包邮条件的，所有运费由消费者承担
  - 包邮商品，消费者仅承担退货运费
  - 7天无理由换货的，消费者承担退回运费、二次寄出运费
  - 商家怠于取回拒签商品产生额外费用的，由商家承担
  - 退货地址致运费明显高于发货地退货的，差额由商家承担
- **第45条**：消费者修改收货地址产生转运费用的，商家应提前沟通，否则由商家承担。
- **第46条**：非消费者原因退换或拒收的，运费由商家承担。
- **第47条**：额外收费场景（上楼费/派送费/搬运费等），商家应在商品页面明确并发货前二次提醒，否则由商家承担。
- **第48条**：运费金额以物流商实际收取为准。

#### 第六节 承诺履约规范

- **第49条**：商家或创作者不得作出无法履行或明显难以履行的承诺。
- **第50条**：承诺存在歧义/不完整/与法规不一致/自相矛盾的，按有利于消费者解释。
- **第51条**：商家应履行承诺；创作者推广中作出的承诺，商家与创作者均负有履行义务。
- **第52条**：商家同意退货后，不得以已知悉或应当知悉的事由拒绝退款。
- **第53条**：承诺附不合理条件的，视为未附条件。
- **第54条**：订单存在试用承诺或带有"试用装"的，商家不能以未退回试用装拒绝退款或要求折价。

#### 第七节 商品少件、破损问题举证责任

- **第55条**：消费者举证收到商品少件/空包/发错货的，商家需提供发货无误凭证（发货清单、视频、物流红章证明、称重照片等）。
- **第56条**：少件成立的，按少发商品实际金额退款；配件/赠品以商家事先声明价值折算，未声明的参照市场公允价。
- **第57条**：消费者举证商品破损的，商家需提供商品完好签收凭证。破损成立的，建议协商补寄/换货；无法协商一致的，支持退货退款。

#### 第八节 质量问题/假冒/描述不符等举证责任

- **第58条**：消费者主张肉眼可识别的质量问题/描述不符/品牌混淆的，应提供初步凭证；已提供凭证且商家未合理解释或反举证的，支持退货退款。
- **第59条**：消费者主张肉眼不可识别的质量问题或假冒的，商家应提供正规进货凭证、出厂合格证、CMA/CNAS质检报告等。商家已提供有效凭证的，消费者应及时提供质检凭证；无法提供的支持商家，提供的支持退货退款。
- **第60条**：商家应对商品描述与实物一致及描述内容合法依据承担最终举证责任。
- **第61条**：商品经送检证实存在问题的，检测、运输费用由商家承担。

### 第四章 撤销和终止

- **第62条**：消费者可主动撤销介入申请。
- **第63条**：平台未完成判定前，交易主体向司法机构起诉/公安报案并提供受理凭证的，平台终止当次介入。

### 第五章 执行

- **第64条**：平台介入包括申请受理和主动介入两种情况。
- **第65条**：订单支持退货/退款的，平台从商家钱款中扣除对应金额，按支付方式原路返还。
- **第66条**：商家支付体验补偿的，平台扣除商家钱款以现金或优惠券形式发放；体验补偿原则上不超过订单实付金额30%，最高200元。
- **第67条**：体验补偿不豁免商家法定赔偿责任。
- **第68条**：平台关闭订单不影响交易主体应承担的其他违约责任。
- **第69条**：平台介入属于《电子商务法》六十三条之争议解决机制范畴。
- **第70条**：规则生效或变更后尚未处理完结的争议，适用生效或变更后的规则。

## 三、运费（运费问题争议处理细则）

> 原文链接：https://school.jinritemai.com/doudian/web/article/113127
> 生效时间：2021年7月15日首次生效，2025年4月15日修订生效

### 第一章 定义

运费，指交易订单在发货、退货、换货、维修等过程产生的必要性物流费用，包含商品拆卸、打包、加固、搬运等相关费用以及运输费用等。

### 第二章 受理范围

买卖双方在平台上交易订单就运费问题产生的争议。

### 第三章 运费规范

#### 3.1 通用原则

- 买卖双方在平台介入前自行达成退换货或维修协议，但未就运费事宜进行说明或约定的，由商家承担运费
- 平台介入后，根据"谁过错、谁承担"的原则处理；双方各有过错的，由先有过错的一方承担
- 卖家有多个运费承诺的，以有利于消费者承诺为准
- 买卖双方另有约定的，从其约定

#### 3.2 场景规范

##### 到付问题

- **3.2.1** 商家未经消费者同意采取到付方式发货的，消费者可选择拒签或签收后要求商家承担到付产生的运费。
- **3.2.2** 消费者未经商家同意采取到付方式退货且商家予以签收商品的，若退货运费本由消费者承担的，则该到付产生的运费仍由消费者承担。

##### 无理由售后

- **3.2.3** 支持7天无理由退货的商品，消费者7天无理由退货或无理由拒签的：
  - 若为非包邮商品，或消费者部分退货致使无法满足包邮条件的，**所有运费均由消费者承担**
  - 若为包邮商品，**消费者仅承担退货运费**
- **3.2.4** 支持7天无理由换货的商品，消费者7天无理由换货的，**由消费者承担换货所产生的相关运费**。
- **3.2.5** 消费者拒绝签收商品后，商家应当及时联系承运人取回商品；若商家怠于取回商品而产生额外的运费、保管费等费用，**由商家自行承担**。
- **3.2.6** 交易由消费者承担退货运费时，若商家提供的退货地址致使消费者的退货运费明显高于向发货地进行退货的运费，**其差额由商家承担**。

##### 有理由售后

- **3.2.7** 平台介入判定商品问题支持消费者退货或换货的，订单涉及的发货、退换货等运费**均由商家承担**。商品问题包含质量问题、描述不符、表面不一致、假冒劣质等。
- **3.2.8** 商家发货或补寄过程中存在发货违规行为或超长时效签收的订单，消费者因此发起退换货的，**相关运费由商家承担**。
- **3.2.9** 商家承诺未做到，消费者发起退货或换货的，**退换货运费由商家承担**。如承诺发货方式未做到、承诺赠品未履约等。
- **3.2.10** 消费者非个人原因拒收或者无法签收商品的，**相关运费由商家承担**。
- **3.2.11** 非消费者原因（如商品质量问题等）需要维修的，因维修产生的相关费用**均由商家承担**，包含商品寄回运费、维修后返回运费等。
- **3.2.12** 商品涉及额外收费场景（上楼费/派送费/搬运费等），商家应在商品页面明确收费标准并发货前二次提醒，否则**由此产生的额外收费、消费者拒收/退货费用由商家承担**。

### 第四章 举证标准

- **4.1** 买卖双方申请平台介入后，平台有权要求双方就运费问题提供举证信息。
- **4.2** 若消费者或商家对需承担运费金额有异议的，相对方需配合提供相关运费凭证。

### 第五章 判责标准

若买卖双方就交易运费问题产生纠纷，平台将根据本规则进行判定。

### 规则解读要点

1. **买卖双方另有约定的，从其约定**：协商一致是双方均认可的方案，一方承诺另一方不认同的，不作为双方约定。
2. **多个运费承诺以有利于消费者为准**：如商品详情页承诺退货包运费，后续飞鸽中表示只承担6元，应按退货实际产生运费要求商家承担。
3. **退货地址异常差额由商家承担**：如商家从广州发货至杭州，退货时要求退至西藏，退货运费明显高于正常退货的，差额由商家承担。
4. **非个人原因拒收运费由商家承担**：如大件商品未经同意放代收点且拒绝送货上门，导致消费者拒收的，商家不能让消费者承担返件或发货运费。
5. **"有理由售后"**：消费者因商家原因或商品问题引发的退、换、维修等售后诉求。

## 四、7天无理由细则（七天无理由退货服务规范）

> 原文链接：https://school.jinritemai.com/doudian/web/article/101835
> 更新时间：2026-07-06

### 第一章 概述

**1.1 目的及依据**

为保障消费者权益，依据《中华人民共和国消费者权益保护法》、《网络购买商品七日无理由退货暂行办法》等相关法律法规及平台协议制定本规范。

**1.2 适用范围**

本规则适用于小店平台内的所有商家和消费者。

**1.3 服务标识**

支持"7天无理由退货"的商品，会在商品详情页的服务保障栏展示标识，具体情况以页面展示的为准。

### 第二章 基础要求

**2.1 退货时效**

消费者需在收到商品之日起七天内，对支持"7天无理由退货"且符合完好标准的商品发起退货申请（一般为物流显示签收商品的次日零时起168小时，即7天内）。

**2.2 赠品处理**

消费者退货时需将商品、配件及赠品（实物、积分、代金券等）一并退回。若赠品无法退回或已损毁，商家可按赠品价值扣除相应价款，但不得因此拒绝商品退货。发票遗失不影响商品退货，若发票遗失，消费者应承担相应税款。

**2.3 商品完好标准**

#### 2.3.1 通用标准

- 商品本体、配件及商标标识完整无缺，不存在受损、受污、刮开防伪涂层、激活（授权）等情况；无难以恢复原状的外观类使用痕迹以及不合理的个人使用数据留存等数据类使用痕迹。
- 因查验需要打开包装或进行合理调试（如确认功能），不影响物品完好性；若超出查验需要而使用商品，致使商品价值较大幅度贬损的，应认定商品不完好。
- 特殊包装（如具备防伪性、唯一性的包装）的商品，商家应当事前显著提示保护要求；未显著提示或包装不具备特殊性的，按一般包装标准处理。

#### 2.3.2 一般商品包装的完好标准

商品原包装未缺失且整体结构完整；在包装、运输或拆卸过程中出现的适度变形、污渍、局部破损等难以避免的形态变化，不认定为影响商品包装的完整性。

#### 2.3.3 特定商品的完好标准

| 商品品类 | 完好标准 |
|---|---|
| **服饰鞋靴** | 1. 商品无显著穿戴、洗涤痕迹；2. 商标标识、防伪/防盗/防损扣/标/贴需保持完好未拆 |
| **运动户外** | 1. 健身训练/骑行类商品未安装/未使用/未激活；2. 户外仪表未实名认证且未联网激活；3. 冲浪潜水类未实际使用 |
| **滋补保健、医疗健康类** | 若有一次性密封外包装需未拆封 |
| **家居电器** | 1. 空调/烘干机/冰洗套未安装；内衣裤清洗机/酒柜/冷柜无使用痕迹；2. 液晶电视和空调允许简单通电调试，未上墙安装；洗衣机未过水使用；3. 厨房大电未安装；厨房小电无使用痕迹；4. 净（滤）水设备未过水使用 |
| **图书音像** | 一次性密封包装需未拆封；书籍无折痕、水渍、污损、字迹、阅读痕迹 |
| **珠宝文玩** | 1. 黄金、投资金银等不适用7天无理由退货；2. 鉴定证书完整/无显著污染；3. 价格标签牌完整 |
| **个护家清/美妆** | 1. 剃须刀/电动牙刷/美容器等与肌肤接触类，一次性密封外包装需未拆封；2. 美妆类一次性密封包装且未拆封 |
| **母婴类** | 尿裤湿巾类商品外包装未拆封 |
| **贴身衣物** | 1. 商标标识、原厂密封包装/封签、防伪/防盗/防损扣/标/贴需完好未拆；无穿戴、洗涤、污损痕迹；2. 内衣/裤、泳衣/裤类保护贴完好未撕 |
| **3C数码/智能设备** | 1. 单反相机快门次数≤20次，无激活/授权信息、不合理个人数据留存；镜头保持一次性密封包装未拆封；2. 游戏软件类一次性密封包装需未拆封；3. Windows系统/Office主机未激活；多功能一体机/打印机未通电；4. 进网许可证完好且无浸液；智能眼镜/VR设备/头盔未使用/未激活；5. 手机类未联网/未配置激活 |
| **食品饮料/宠物食品及用品** | 一次性密封外包装需未拆封 |
| **玩具/乐器类** | 1. 若有胶条/塑封，需保持未拆封状态；2. 商标标识、防伪/防盗/防损扣/标/贴需完好未拆 |
| **汽车/自行车零配件** | 1. 汽车/摩托车/电动车零配件无使用/安装痕迹，电池/电瓶未通电；2. 汽车耗材类一次性密封包装未被拆封 |
| **箱包皮具** | 1. 无显著使用痕迹/磨损/划痕；2. 商标标识、防伪/防盗/防损扣/标/贴需完好未拆 |
| **家居用品** | 1. 家居类和家纺类商标标识未被摘除或裁剪，商品无污损，封签未拆封/移位/撕毁；床垫表面保护薄膜未破损；2. 净化除味/一次性毛巾/浴巾类一次性密封外包装未破损，香薰蜡烛无使用痕迹 |
| **家具家装** | 1. 桌/床/柜/架/椅等组装类家具尚未安装；床垫表面保护薄膜未破损且无使用痕迹；马桶/浴室柜/智能门锁/灯饰等未安装；2. 地板/瓷砖/壁纸无使用痕迹；3. 涂料漆类一次性密封外包装需未拆封；4. 定制类主材不支持7天无理由退货 |
| **电子仪器类** | 1. 电子电器类无未经授权维修/改动，无破坏/涂改强制性产品认证标志等；无难以恢复原状的外观使用痕迹，无激活/授权信息、个人数据留存；2. 电子元器件商品未焊接操作，易耗品一次性密封包装未拆封 |
| **打火机类** | 1. 棉芯未注油使用；2. 打火轮/火石无明显磨损 |
| **二手奢侈品** | 1. 防伪签/防盗扣/原膜完好；2. 无新增穿戴/使用/洗涤/污损/划痕/磨损痕迹 |

> 注：密封，指商品外包装被生产厂商加以了封条（签）或整体塑（密）封的包装措施。

### 第三章 服务分类与标识

#### 3.1 适用范围分类

| 是否适用 | 商品类型 | 举例 |
|---|---|---|
| **不适用7天无理由退货** | 定制类商品 | 个性定制、设计服务等 |
| | 鲜活易腐类商品 | 鲜花绿植、水产肉类、新鲜蔬果、活体类等 |
| | 在线下载或拆封的数字化商品 | 充值点卡、加油卡等 |
| | 交付的报纸、期刊 | 期刊杂志等 |
| | 服务类 | 本地服务类、教育培训、装修设计/施工/监理等 |
| | 人体用药 | / |
| **商家可选支持** | 拆封后影响人身安全或生命健康，或拆封后易导致品质改变的商品 | 食品、酒水、内裤、塑身裤、乳贴等贴身用品 |
| | 一经激活或试用后价值贬损较大的商品；或非生活消费所需商品 | 智能设备（如VR头盔）、商用厨具、工业品、电动车整车、黄金、铂金、投资贵金属等 |
| | 其他根据商品性质并在消费者购买时确认不宜退货的商品 | 临近保质期/有瑕疵的商品等 |
| **适用7天无理由退货** | 除上述类型外的其他商品 | 服装鞋靴（除贴身用品）、家居日用、家纺类、厨房/烹饪用具、家电等 |

#### 3.2 服务分类

| 分类 | 说明 | 商品举例 |
|---|---|---|
| **支持7天无理由退货** | 签收后7天内商品完好情况下，因主观原因申请退货 | 服饰、鞋靴、童装童鞋类等 |
| **7天无理由退货（一次性包装未破损）** | 外包装已拆封、缺少附件、外观损坏等任一不完好情形，均不适用 | 个护清洁、食品、美妆等 |
| **7天无理由退货（安装后不支持）** | 已安装、缺少附件、外观损坏等任一不完好情形，均不适用 | 健身车、踏步机、挂装空调等 |
| **7天无理由退货（激活后不支持）** | 已激活、缺少附件、外观损坏等任一不完好情形，均不适用 | 笔记本、台式机、手机等 |
| **7天无理由退货（使用后不支持）** | 已使用、缺少附件、外观损坏等任一不完好情形，均不适用 | 冲浪服、刻录碟片、香薰蜡烛等 |
| **7天无理由退货（定制类不支持）** | 定制类商品不适用7天无理由退货 | 定制家居、定制服装等 |
| **7天无理由退货（合约版不支持）** | 合约版商品不适用7天无理由退货 | 合约版（联通/电信/移动）手机 |
| **7天无理由退货（防伪签、密封条、原膜损毁不支持）** | 封签、防伪签、密封条、商品原膜损毁、缺少配件、外观新增磨损等任一不完好情形，均不适用 | 二手3C数码、二手奢侈品等 |

#### 3.2.2 服务规范

- 商家应根据商品真实属性及合理附加条件，正确选择对应的服务标签，不得任意扩大不适用/有条件适用的商品范围。
- 拆封/激活/安装/使用后不支持7天无理由退货的商品、临期商品、瑕疵商品等，商家未选择正确服务标签的，商品已拆封/已激活等情况不能作为影响商品完好的依据，商家也不得以已告知为由拒绝履行7天无理由退货义务。
- 平台要求支持7天无理由退货的商品，商家单方或双方约定不支持的行为无效（平台判断消费者为非生活消费所需购买的情形除外）。
- 商家违反服务规范的，平台有权限期整改；逾期未整改或整改不符合要求的，有权对相关商品采取下架等处置措施。

### 第四章 附则

- 平台有权依据运营情况对规则进行调整，并以公告形式予以公示。
- 商家应严格遵守国家法律法规以及与平台所签订的协议，依法依规承担相应法律责任和接受平台处置。
